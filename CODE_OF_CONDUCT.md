# Code of Conduct / Правила поведения

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. In short: be kind and constructive, assume good faith, no harassment, no personal attacks, no publishing of others' private information.

It applies in issues, pull requests, discussions and comments in this repository. To report a problem, contact the maintainer [@KROU4](https://github.com/KROU4) through a [private security advisory](https://github.com/KROU4/claude-code-mod-showroom/security/advisories/new) or by opening an issue. Reports are handled confidentially.

---

Проект принимает [Contributor Covenant версии 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) как свои правила поведения. Коротко: будьте доброжелательны и конструктивны, исходите из добрых намерений, никаких оскорблений, травли и публикации чужих личных данных.

Правила действуют в issues, pull request, обсуждениях и комментариях этого репозитория. Чтобы сообщить о нарушении, напишите мейнтейнеру [@KROU4](https://github.com/KROU4) через [приватный security advisory](https://github.com/KROU4/claude-code-mod-showroom/security/advisories/new) или откройте issue. Сообщения рассматриваются конфиденциально.
